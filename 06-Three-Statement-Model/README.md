# 06 — Fully Linked 3-Statement Model

## Overview

Fully linked 3-statement financial model (Income Statement → Balance Sheet → Cash Flow Statement) with Bull/Base/Bear scenario analysis and sensitivity table. Net income ranges from $2.0M (Bear) to $3.3M (Bull).

## Key Features

- All three statements dynamically linked — changes cascade through margins, working capital, and cash flow
- Bull/Base/Bear scenario toggle (+10% / Base / -10% revenue with corresponding COGS adjustments)
- 7x7 sensitivity table on Revenue Growth × COGS %
- Balance sheet balances in all scenarios (Assets = Liabilities + Equity)
- Ending Cash on Cash Flow ties to Cash on Balance Sheet

## Scenario Results

| Scenario | Revenue | Net Income |
|----------|---------|------------|
| Bull (+10%) | $9.5M | $3.3M |
| Base | $8.7M | $2.6M |
| Bear (-10%) | $7.8M | $2.0M |
